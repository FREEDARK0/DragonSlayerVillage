# Dragon Slayer Village 游戏规则

## 1. 游戏目标

玩家经营一个位于八边形中心的村庄，通过购买、放置、升级建筑和单位来抵御龙的吐息。村庄战力归零时游戏结束。当前规则没有固定胜利回合，目标是尽可能存活更久。

## 2. 基础概念

### 2.1 棋盘

- 棋盘由 8 个环形扇区和中心村庄组成。
- 扇区编号可理解为顺时针 1-8；龙停留在对应外侧边，攻击时会影响面前扇区。
- 旋转棋盘会改变扇区与龙外侧边的相对位置，因此会影响龙吐息命中的扇区。
- 每个扇区最多存在 1 个地块。地块可能是友方建筑/单位，也可能是金矿或龙焰。
- 中心村庄拥有“村庄战力”，初始为 50。村庄战力既是生命值，也是购买和扩展商店的资源。

### 2.2 初始布局

- 开局随机生成 3 个金矿、2 个木墙、3 个空地。
- 金矿生成时获得 1-20 随机战力。
- 木墙初始战力为 10。

### 2.3 村庄等级

村庄等级由当前村庄战力决定：


| 村庄战力   | 村庄等级 |
| ---------- | -------: |
| 0-59       |        0 |
| 60-79      |        1 |
| 80-119     |        2 |
| 120-199    |        3 |
| 200 及以上 |        4 |

## 3. 回合流程

每回合由玩家行动和自动结算组成。

### 3.1 玩家行动

在确认回合前，玩家可以反复执行以下操作：

- 旋转棋盘。每次有效旋转为 45 度，部分单位会根据本回合旋转步数成长。
- 从商店购买并放置建筑/单位。
- 购买并释放法术。
- 扩展商店分区。
- 将刷新区商品拖入锁定区保存。

以上购买、施法、扩展都不会自动结束回合。玩家旋转到满意的角度并点击确认后才回合结束进入结算。

### 3.2 自动结算顺序

确认回合后依次结算：

1. 村庄获得基础收入和地块收入。
2. 友方地块的每回合效果生效。
3. 冷却减少。
4. 所有存活龙依次行动。
5. 若村庄战力归零或更低，游戏结束。
6. 尝试生成新龙。
7. 黑夜范围变化，并处理默认黑夜离场。
8. 存活龙的停留回合数增加。
9. 回合数 +1，进入下一次玩家行动。

基础收入为每回合 +10 村庄战力。

## 4. 黑夜规则

- 黑夜覆盖若干连续外侧边。
- 开局黑夜覆盖 4 个边，之后先收缩再扩张，循环变化。
- 收缩时：黑夜起点顺时针移动 2 格，长度减少 2。长度降至 0 后改为扩张。
- 扩张时：黑夜长度增加 2。长度达到 8 后改为收缩。
- 默认离场规则：没有专属离场条件的龙，如果当前不在黑夜中，但下一回合黑夜将覆盖它所在边，则会离开。
- 有专属离场条件的龙不使用默认黑夜离场。

## 5. 商店规则

### 5.1 分区

商店分为 5 个区：


| 分区 | 初始槽位 | 规则                   |
| ---- | -------: | ---------------------- |
| 锁定 |        1 | 保存商品，不会自动刷新 |
| 资源 |        2 | 只出现资源类商品       |
| 防御 |        2 | 只出现防御类商品       |
| 进攻 |        2 | 只出现进攻类商品       |
| 法术 |        1 | 只出现法术             |

- 同一时间所有可见商品不会重复。
- 从刷新区购买成功后，该槽位会立即补充同类分区的新商品。
- 从锁定区购买成功后，锁定商品仍保留，可重复购买。
- 将刷新区商品拖入锁定区时，会覆盖目标锁定槽，来源槽立即刷新。

### 5.2 扩展

- 任意分区都可扩展槽位。
- 全商店总槽位上限为 15。
- 第 1 次扩展消耗 50 村庄战力。
- 每扩展 1 次，下一次扩展费用 +30。
- 扩展费用序列：50、80、110、140……

## 6. 放置、升级与费用

- 购买商品时，如果村庄战力不足，无法购买。
- 建筑/单位只能放在空地、同类地块或龙焰上。
- 放在空地：生成 Lv1 地块。
- 放在同类地块：升级 1 级，最高 Lv3。
- 放在其他类型地块：无法放置。
- 放在龙焰上：不会生成地块，而是用该商品初始战力削减龙焰战力；龙焰战力降至 0 或更低时消失。
- 成功购买、放置、升级、施法或扩展后，立刻扣除对应村庄战力。
- 友方地块包括所有可购买建筑/单位，不包括金矿、弱点、龙焰。

## 7. 战斗规则

### 7.1 龙的攻击

- 龙的基础攻击倍率为 0.3。
- 吐息伤害 = 当前龙战力 x 攻击倍率，四舍五入。
- 吐息范围由龙的吐息强度决定：
  - 强度 1：攻击面前 1 个扇区。
  - 强度 2：攻击面前 3 个扇区。
  - 强度 3：攻击面前 5 个扇区。
- 多格吐息从中心扇区开始结算，再同时结算左右对称扇区。

### 7.2 命中地块

- 命中普通地块时，地块战力减少吐息伤害。
- 地块战力降至 0 或更低时，该地块被摧毁。
- 如果地块被打成负战力，溢出的负值会继续扣除村庄战力。
- 部分地块会在被命中、被摧毁或受到伤害时触发特殊效果。

### 7.3 命中空地

- 吐息命中空地时，村庄战力减少吐息伤害。
- 特殊龙可能在空地生成金矿或龙焰。
- 如果有感应石墙在场，空地被攻击前，最近的感应石墙会自动移动到目标空地抵挡。

### 7.4 先攻

- 带“先攻”的地块位于吐息中心扇区时，会在龙吐息前攻击该龙。
- 如果先攻击杀龙，则本次吐息取消。

### 7.5 龙死亡与复活

- 龙战力降至 0 或更低即被击败。
- 被击败的龙会进入等待，第 6 个回合后可重新进入刷新池。
- 重新出现时，战力、攻击倍率和特殊计数恢复为该年份的初始状态。
- 自然离开的龙不会进入复活等待。

## 8. 友方地块与法术

所有可升级地块最高 Lv3。

### 8.1 木墙

- 价格：5。
- 标签：无法攻击。
- 战力：
  - Lv1：10。
  - Lv2：25。
  - Lv3：50。
- 效果：阻挡吐息。升级时战力恢复到该等级满值。

### 8.2 巨弩

- 价格：30。
- 战力：
  - Lv1：5。
  - Lv2：15。
  - Lv3：30。
- 效果：攻击同扇区外侧边上的龙。
- 伤害：
  - Lv1：自身战力 x2。
  - Lv2：自身战力 x3。
  - Lv3：自身战力 x3。
- 冷却：
  - Lv1：2 回合。
  - Lv2：2 回合。
  - Lv3：1 回合。

  - Lv2：30%。
  - Lv3：40%。

### 8.4 矿厂

  - Lv3：每旋转 1 步 +3。

### 8.15 法师

- 初始战力：8。

  - 基础伤害 = 自身战力 + 左右相邻地块战力。
  - 最终伤害倍率：
    - Lv1：x1。
    - Lv2：x1.5。
    - Lv3：x2。

### 8.16 巫毒娃娃

### 8.17 金矿

- 生成时随机获得 1-20 战力。
- 被摧毁时，村庄获得“生成时战力 x 此金矿当前等级”的战力。

### 8.19 龙焰

- 非商店敌对地块。
- 基础战力：10。
- 每回合对村庄造成等同自身战力的伤害。
- 玩家将建筑/单位放到龙焰上时，改为削减龙焰战力，不会生成该建筑/单位。

## 9. 法术

### 9.1 集中力场

- 价格：20。
- 目标：1 个友方地块。
- 效果：
  - 吸收左右相邻友方地块各一半战力，向下取整。
  - 被吸收的战力从来源扣除，并加到目标上。
  - 若没有可吸收的相邻战力，则释放失败且不消耗。

### 9.2 献祭

- 价格：15。
- 目标：1 个友方地块。
- 效果：
  - 摧毁目标。
  - 随机升级另一个未满 Lv3 的友方地块。
  - 若没有可升级的其他友方地块，则释放失败且不消耗。

### 9.3 壁垒

- 价格：30。
- 目标：无需选择目标。
- 效果：
  - 所有带“无法攻击”的友方地块 +5 战力。
  - 若没有可强化目标，则释放失败且不消耗。

### 9.4 盾牌碾压

- 价格：25。
- 目标：1 个带“无法攻击”的友方地块。
- 效果：
  - 摧毁目标。
  - 对同扇区外侧边上的龙造成等同目标当前战力的伤害。
  - 若该扇区没有龙，则释放失败且不消耗。

## 10. 龙生成规则

### 10.1 同时存在数量

回合结束时会尝试生成新龙，但会受到当前回合数的全局上限限制：


| 下一回合数 | 最多存活龙数 |
| ---------: | -----------: |
|        1-3 |            2 |
|        4-9 |            3 |
|      10-15 |            5 |
|  16 及以后 |       无限制 |

### 10.2 出现条件

- 只会从当前年份已解锁的龙中随机选择。
- 选择时按出现权重随机。
- 每种龙有同时存在上限。
- 新龙只会出现在未被其他龙占用的外侧边。
- 同一年份下，龙初始战力 = 基础战力 x [1 + (年份 - 1) x 15%]，四舍五入。
- 所有龙出现时攻击倍率为 0.3。

## 12. 各龙详细规则

### 12.1 伊格尼斯

- 类型：高傲。
- 吐息强度：2，固定覆盖 3 个扇区。
- 特殊效果：
  - 中心扇区正常造成伤害。
  - 两侧扇区若命中地块，不造成伤害，改为给地块增加等同吐息伤害的战力。
  - 每次攻击后，攻击倍率 x1.1。
- 离场：默认黑夜离场。

### 12.2 古洛

- 类型：贪食。
- 吐息强度：1，覆盖 1 个扇区。
- 特殊效果：
  - 每次攻击后，攻击计数 +1。
  - 攻击后会吞噬最近的其他白天区域龙。
  - 被吞噬的龙视为被击败，进入复活等待。
  - 古洛获得被吞噬龙的当前战力，并移动到被吞噬龙所在边。
  - 黑夜中的其他龙不会被吞噬。
- 离场：攻击 2 次后离开。

### 12.3 弗罗

- 类型：破坏。
- 吐息强度：
  - 停留回合数为偶数时：2，覆盖 3 个扇区。
  - 停留回合数为奇数时：1，覆盖 1 个扇区。
- 特殊效果：
  - 如果本次攻击击破了地块，会顺时针移动 1 边并继续攻击。
  - 单回合最多连续追击 8 次。
- 离场：场上地块少于 3 个时离开。

### 12.4 奥鲁斯

- 类型：黄金。
- 吐息强度：1，覆盖 1 个扇区。
- 特殊效果：
  - 吐息命中空地时，该空地生成 1 个 Lv1 金矿。
  - 空地仍会对村庄造成吐息伤害。
  - 若感应石墙移动来抵挡，则不会触发空地生成金矿。
- 离场：默认黑夜离场。

### 12.5 亚龙

- 类型：亚龙。
- 吐息强度：1，覆盖 1 个扇区。
- 特殊效果：
  - 受到任意伤害后标记为受伤。
- 离场：受伤后的回合结束时离开。

### 12.6 布鲁图斯

- 类型：暴虐。
- 吐息强度：1，覆盖 1 个扇区。
- 特殊效果：
  - 攻击结算后，在攻击范围内的空地生成 10 战力龙焰。
  - 若攻击范围内已有龙焰，则该龙焰 +10 战力。
  - 吐息命中已有龙焰时，不会对龙焰造成普通伤害。
- 离场：默认黑夜离场。

### 12.7 索尔

- 类型：太阳。
- 吐息强度：1，覆盖 1 个扇区。
- 特殊效果：释放耀光吐息；当前没有额外结算效果。
- 离场：默认黑夜离场。

### 12.8 诺克斯

- 类型：暗影。
- 吐息强度：1，覆盖 1 个扇区。
- 特殊效果：释放暗影吐息；当前没有额外结算效果。
- 离场：默认黑夜离场。
