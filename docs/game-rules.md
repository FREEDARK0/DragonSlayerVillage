# Dragon Slayer Village 游戏规则

## 1. 游戏目标

玩家经营八边形中心的村庄，通过购买、放置建筑/单位和释放法术抵御龙。村庄拥有两个独立属性：

- 生命值：初始 50，降至 0 或更低时失败。
- 金币：初始 10，用于购买商品和刷新商店。

当前规则没有固定胜利回合，目标是尽可能存活更久。

## 2. 棋盘与回合

- 棋盘由 8 个环形扇区和中心村庄组成。
- 每个扇区最多存在 1 个地块。地块可能是友方建筑/单位、金矿、巫毒娃娃或龙焰。
- 开局随机生成 3 个金矿、2 个木墙、3 个空地。
- 每回合村庄获得 5 金币，矿场、酒馆等地块会追加金币收入。
- 玩家可在行动阶段旋转棋盘、购买放置、释放法术、刷新商店、锁定/解锁随机商品。
- 确认回合后依次结算金币收入、地块回合效果、友方攻击、龙行动、失败检查、龙生成、黑夜变化。

## 3. 商店

商店分为基础区和随机区：

- 基础区 3 格常驻：木墙、矿场、飞弹。
- 随机区 4 格；购买未锁定商品后自动补空。
- 随机区不会刷出基础区商品，且可见随机商品不重复。
- 每个随机商品下方有锁定按钮；锁定后刷新不会替换该商品，再次点击解除锁定。
- 已锁定商品购买后保留并继续锁定，可重复购买。
- 刷新按钮位于商店最右侧。每回合初始刷新花费 1 金币，同一回合内每次刷新后花费 +2，下回合重置。

## 4. 放置与战斗

- 建筑/单位只能放在空地或龙焰上；不再有升级。
- 放在空地会生成对应地块。
- 放在龙焰上不会生成地块，而是用该商品 HP 削减龙焰 HP。
- 龙吐息伤害直接等于龙攻击力。
- 命中地块时，地块 HP 减少；HP 为 0 时摧毁。
- 命中空地时，村庄生命值减少。
- 友方攻击力大于 0 的建筑/单位会在玩家阶段攻击同扇区龙。

法术：

- 集中防御：价格 20，选择友方，吸收相邻友方一半 HP，向下取整。
- 集中突破：价格 25，选择友方，吸收相邻友方一半攻击力，向下取整。
- 献祭：价格 20，摧毁选择友方，将其 HP/攻击的一半传递给随机友方。
- 壁垒：价格 15，所有攻击力为 0 的友方 +5 HP。
- 盾牌碾压：价格 25，选择攻击力为 0 的友方摧毁，并对其扇区敌人造成其 HP 的伤害。
